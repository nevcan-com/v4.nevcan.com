# nevcan.com v4 (2014)

The fourth version of nevcan.com, live in 2014: a one-page portfolio as a frontend developer,
"I am NEVCAN and I'm a web Expert / Developer / Designer" with the last word rotating, then what I
do, about me, my works and contact.

`/dalgic` is the diving page added in August 2015, the first appearance of the design that became
v5 (nevcan.com from 2016).

Online at **[v4.nevcan.com](https://v4.nevcan.com)** as part of the nevcan.com version archive,
hidden from search engines. The current site is [www.nevcan.com](https://www.nevcan.com).

## Source

There was no copy of this version's code. It was restored from the Internet Archive's Wayback
Machine in 2026; [RESTORE-REPORT.md](RESTORE-REPORT.md) lists every file's capture, the changes made
so it runs today, and what is still missing.

## Stack

HTML, CSS, Bootstrap 3, jQuery (FlexSlider, Masonry, Waypoints, EasyPieChart, scrollTo), Font
Awesome 3, Lato from Google Fonts; the "Designr" theme (cyan). Hosted on GitHub Pages.
